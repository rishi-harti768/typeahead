# Mission: Scalable Search Typeahead System

## Why
Master the engineering principles of a scalable search typeahead system to ace FAANG-level backend system design interviews. Gaining this skill will allow the learner to confidently design, discuss, and build low-latency distributed data systems with concrete trade-off reasoning.

## Success looks like
- Confidently explain Trie, Consistent Hashing, and Write-Buffered Caching architectures during a system design interview.
- Build a working backend in Node.js that serves top-10 autocomplete suggestions with sub-10ms response times.
- Implement a distributed caching tier using consistent hashing to partition key space across multiple virtual nodes.
- Design and evaluate a recency-aware ranking mechanism using exponential decay to balance historical count against immediate trends.

## Constraints
- **Language**: Node.js (learner is intermediate).
- **Background**: Beginner in Data Structures (Tries, Hash Rings) and System Design Concepts (Distributed caching, Write buffers).
- **Teaching Style**: Highly visual, step-by-step logic, bite-sized lessons, interactive browser-based visualizers.

## Out of scope
- Production cluster deployment (Kubernetes, AWS setup).
- Real production databases (we will model storage in-memory/JSON files to focus on algorithmic and architectural mechanics).
- Elaborate frontends (we will build a clean, minimalist UI).
