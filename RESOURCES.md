# Scalable Typeahead System Resources

## Knowledge

- [Article: "Design a Search Autocomplete System" — Alex Xu (ByteByteGo)](https://bytebytego.com/courses/system-design-interview/design-a-search-autocomplete-system)
  The gold-standard reference for Autocomplete system design. Explains Trie data structure optimization, distributed cache layers, data collection services, and real-time updates.
- [Repository: "The System Design Primer: Autocomplete" — Donne Martin](https://github.com/donnemartin/system-design-primer)
  Open-source reference detailing scalable web architectures, write-ahead logs, and database choices for search indexing.
- [Article: "Consistent Hashing" — Tom White](https://www.tom-e-white.com/2007/11/consistent-hashing.html)
  The seminal blog post explaining consistent hashing with virtual nodes in Java. Perfect for understanding key redistribution.
- [Documentation: "Redis Sorted Sets (ZSET)" — Redis](https://redis.io/docs/latest/develop/data-types/sorted-sets/)
  Official documentation on Redis ZSETs, which are widely used to maintain real-time trending leaders with fast ranking updates.

## Wisdom (Communities)

- [r/SystemDesign](https://reddit.com/r/SystemDesign)

- [System Design Fight Club (YouTube/Discord)](https://www.youtube.com/@SystemDesignFightClub)
